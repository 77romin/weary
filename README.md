# !WEARy

> 옷을 산 순간부터 입은 날들, 그리고 다음 주인에게 보내는 순간까지.

**WEARy**는 내 옷을 중심으로 개인 옷장 관리, 데일리룩 커뮤니티, 패션 중고거래를 연결하는 패션 라이프사이클 플랫폼입니다.

사용자는 옷을 구매하거나 기존 옷장을 정리할 때 사진과 정보를 등록합니다. 매일 전신 착장을 촬영하면 앱이 옷장에 등록된 옷을 찾아 착용 횟수와 마지막 착용일을 기록합니다. 착장은 선택적으로 커뮤니티에 공유할 수 있고, 오랫동안 입지 않은 옷은 기존 정보를 활용해 중고 판매 글로 전환할 수 있습니다.

## 핵심 사용자 흐름

```text
옷 구매 또는 기존 옷 등록
        ↓
아침에 전신 착장 촬영
        ↓
내 옷장에서 착용한 옷 매칭
        ↓
사용자 확인 후 착용 기록 확정
        ↓
원하면 데일리룩을 커뮤니티에 공유
        ↓
착용 통계로 잘 입지 않는 옷 발견
        ↓
기존 옷 정보로 중고 판매 글 생성
```

AI는 착용 기록을 자동으로 확정하지 않습니다. 후보를 제안하고, 사용자가 최종 확인한 기록만 통계에 반영합니다.

## 제품 구성

### 개인 옷장

- 기존 옷 빠른 등록 및 새로 구매한 옷 상세 등록
- 사진, 카테고리, 브랜드, 구매일, 가격, 사이즈, 색상, 계절 관리
- 전신 착장 사진에서 등록된 옷의 매칭 후보 제시
- 총 착용 횟수, 착용일수, 마지막 착용일 및 기간별 기록 제공
- 구매 가격을 기반으로 한 1회 착용 비용 계산
- 등록 사진의 배경을 제거한 투명 옷 썸네일 저장
- MY 월간 캘린더에서 날짜별 착장 조합 확인
- 유지, 보관, 처분 예정 상태 관리

### 패션 커뮤니티

- 데일리룩 피드와 착용 아이템 연결
- 좋아요, 댓글, 저장 및 팔로우
- 개인 착장 기록과 공개 게시물을 명확히 분리
- 옷 또는 스타일 태그를 통한 코디 탐색

### 패션 중고거래

- 미착용 데이터에 기반한 판매 제안
- 기존 사진과 상품 정보로 판매 글 초안 자동 생성
- 판매자가 착용 횟수와 착용 사진 공개 여부 선택
- 패션 상품 중심의 목록, 상세, 채팅 및 구매 요청
- 거래 완료 시 개인 옷장의 상태와 연결

## 앱 구조

| 탭 | 역할 |
| --- | --- |
| 피드 | 데일리룩과 스타일 탐색 |
| 옷장 | 내 옷과 착용 데이터 관리 |
| 촬영 | 오늘의 착장 기록을 시작하는 핵심 행동 |
| 마켓 | 패션 중고 상품 탐색 및 판매 |
| MY | 내 착장, 게시물, 통계와 설정 |

## 데이터 저장 방향

- 옷, 비공개 착장, 구매 정보와 착용 통계는 사용자의 개인 데이터입니다.
- 프로토타입은 기기 내부 SwiftData에 저장하며, 정식 버전에서는 SwiftData와 CloudKit 개인 데이터베이스를 연결합니다.
- 같은 Apple 계정과 iCloud 컨테이너를 사용하면 기기 변경이나 앱 재설치 후에도 개인 옷장을 복원할 수 있게 설계합니다.
- 커뮤니티 게시글, 댓글, 팔로우, 신고와 중고거래 정보는 여러 사용자가 공유하므로 별도의 서비스 서버 영역으로 분리합니다.
- 개인 착장을 커뮤니티에 게시할 때는 사용자가 공개를 확정한 데이터만 서버로 복사합니다.

CloudKit 세부 구성과 커뮤니티 서버 기술 선택은 다음 단계의 ERD 및 동기화 정책 설계에서 확정합니다.

상세한 제품 정의와 설계 원칙은 [PRODUCT_CONCEPT.md](./PRODUCT_CONCEPT.md)에서 확인할 수 있습니다.
발표 순서와 복구 방법은 [DEMO_GUIDE.md](./DEMO_GUIDE.md)에서 확인할 수 있습니다.
개인 iCloud와 공용 서버의 데이터 경계 및 ERD는 [DATA_ARCHITECTURE.md](./DATA_ARCHITECTURE.md)에서 확인할 수 있습니다.

## 구현 원칙

- 개인 옷장과 착장 기록을 먼저 완성한 뒤 커뮤니티와 마켓을 연결합니다.
- 착용 통계는 확정된 착장 기록을 원천 데이터로 계산합니다.
- AI 또는 네트워크가 실패해도 사용자가 직접 옷을 선택해 기록할 수 있어야 합니다.
- 개인 착장은 기본적으로 비공개이며 사용자가 선택한 경우에만 게시합니다.
- 이번 프로토타입은 로컬 데이터와 결정론적 Mock으로 시연 안정성을 확보합니다.
- 서버와 실제 AI는 교체 가능한 인터페이스 뒤에 분리합니다.

## 시연 완료 조건

1. 사용자가 옷을 사진과 구매 정보로 등록한다.
2. 전신 착장 사진을 선택한다.
3. 앱이 상의, 하의, 신발 후보를 제시한다.
4. 사용자가 후보를 수정하고 착장을 확정한다.
5. 해당 옷의 착용 횟수와 마지막 착용일이 갱신된다.
6. 착장을 커뮤니티에 게시한다.
7. 오랫동안 입지 않은 옷을 판매 대상으로 선택한다.
8. 기존 정보로 만들어진 판매 글을 마켓에 등록한다.

## 로컬 실행

```bash
xcodegen generate
open WEARy.xcodeproj
```

명령행 빌드는 다음과 같이 검증할 수 있습니다.

```bash
xcodebuild -project WEARy.xcodeproj \
  -scheme WEARy \
  -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO \
  build
```

전체 단위·UI 테스트는 다음과 같이 실행합니다.

```bash
xcodebuild -project WEARy.xcodeproj \
  -scheme WEARy \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO \
  test
```
